# README translations

[English README](../../README.md)

The English README is authoritative. This catalogue provides **30 locale versions**:
English and 29 full translations, covering 29 languages with two Chinese scripts.

Translations are AI-assisted and independently reviewed for meaning, terminology,
and technical caveats. Automated checks preserve code examples, inline identifiers,
numeric literals, section anchors, and link targets. **Human or native-speaker
review is not claimed.** For implementation and security decisions, consult the
[English README](../../README.md) and the [English protocol specification](../../a4a-master-spec.md).

## Selection and maintenance

The translation set balances worldwide speaker reach and developer communities.
Modern Standard Arabic, Brazilian Portuguese, Gurmukhi Punjabi, and the two
Chinese script variants are deliberate locale choices.

Translate explanatory prose while keeping protocol identifiers, commands, and
executable examples in English. Stable English section anchors preserve incoming links.
To report a translation issue, name the locale, quote the English passage, and
suggest a correction through the process in [CONTRIBUTING.md](../../CONTRIBUTING.md).
